## How to Compile and Run

Make sure you have GCC installed, then:

```bash
gcc program_name.c -o program_name
./program_name
```

On Windows (MinGW):

```bash
gcc program_name.c -o program_name.exe
program_name.exe
```

## Program Naming Convention

Files are named by what they do, in lowercase with underscores:

`factorial_recursion.c`, `reverse_string.c`, `matrix_multiplication.c`
